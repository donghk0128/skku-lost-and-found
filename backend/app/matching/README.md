# Matching

`GET /api/v1/posts/{post_id}/recommendations`는 공개 게시글의 추천 후보를 요청 시 계산합니다. 기본 5개를 반환하며 `limit`으로 1~20개를 요청할 수 있습니다.

- 원본 글이 `LOST`면 `FOUND`, `FOUND`면 `LOST` 글을 찾습니다.
- 후보는 `OPEN`이고 삭제되지 않은 글만 사용합니다. 완료된 원본 글의 결과는 빈 목록입니다. 없는 글이나 삭제된 원본 글은 `404`입니다.
- 글자 유사도, 같은 카테고리, 발생 시각 간격, 좌표 거리를 함께 사용해 내림차순으로 정렬합니다. 좌표나 발생 시각이 없어도 후보에서 제외하지 않습니다.
- 응답의 `score`는 임시 순위 점수(0~1)이며 같은 물건일 확률이 아닙니다. 임베딩 모델은 아직 사용하지 않습니다.
- 결과는 DB에 저장하지 않으므로 새 글이나 상태 변경이 있으면 다음 요청에서 달라질 수 있습니다.

현재 모든 후보를 읽어 애플리케이션에서 점수를 계산합니다. 글이 많아지면 후보 조회 범위와 인덱스를 조정해야 합니다. 텍스트 점수는 `scoring.py`에 분리해 임베딩을 나중에 연결할 수 있습니다.
